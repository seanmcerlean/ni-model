# Northern Ireland Population and Voting Model

## Project Objective
Build a demographic simulation system that models Northern Ireland's ~2 million population at individual person level in a relational database. Generate voting predictions through iterative population updates.

## Core Requirements

### Population Model
- Individual person records in relational database
- Required attributes: Age, Religious Background, Gender, Education Level, Location
- Expandable to additional attributes over time
- Must support rollback to known starting points

### Simulation Engine
- MANDATORY: All results generated by sequential DB population updates
- Process similar to: Calculate births → Update DB → Calculate deaths → Update DB → Calculate migration → Update DB → Generate results
- This iterative approach required regardless of model complexity
- Migration tracks movement in/out of Northern Ireland

### Model Architecture
- Modular, swappable model implementations (basic/simple/sophisticated)
- Models accept configurable parameters
- Complete model replacement capability
- All models must follow same DB update simulation pattern

### Data Sources
- Public data: census, election results, government statistics
- Initial development uses test data
- Historical data for model validation against actual results

### Technology Constraints
- Backend: Python with suitable data libraries
- Web deployment: Each user runs independent model instance
- Support multiple concurrent user sessions with custom assumptions
- Frontend: Technology agnostic
- Database: Lightweight, web-compatible solution

### Validation Requirements
- Test models using historical data vs actual election results
- Ability to simulate N years forward from any baseline
- Reproducible results from same starting conditions

## Development Approach
- Start simple, expand complexity incrementally
- Follow PEP8 and testing standards
- AI creates implementation plan before coding
- Execute steps only when explicitly approved
- Efficient code is helpful
